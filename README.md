# 🚀 What I’m Building

## Skyvb’s IDE

*A CLI-based lightweight educational IDE for C++ and future embedded workflows*

A minimal C++ command-line IDE designed not just for editing and running code, but for helping learners understand **what happens internally during compilation**.

### Current Features

✔ Undo / Redo using stacks
✔ File operations (save / load / rename / delete / edit)
✔ Multi-line edit mode
✔ Color-coded terminal output
✔ Modular C++ architecture
✔ Build and Run commands

### New Direction: Transparent Compilation

Instead of treating compilation as a single hidden command, the IDE is evolving to explicitly show each stage of the C/C++ build pipeline:

* Preprocessing
* Compilation
* Assembly generation
* Object file creation
* Linking

Example internal flow:

g++ file.cpp -E -o file.i

g++ file.cpp -S -o file.s

g++ file.cpp -c -o file.o

g++ file.o -o main

The goal is to make compilation visible so beginners can understand how source code becomes an executable.

### Long-Term Goal

Turn this into a lightweight educational CLI environment for:

* C++ systems learning
* Embedded development workflows
* ESP32 / Arduino build support
* Beginner-friendly compiler understanding
